# shubhankarnehra.com

My portfolio. You scroll down from a blue sky to a meadow, and each card there
opens a section built in 3D.

**Live:** https://shubhankarnehra.com

- **Skills:** a chess board where every piece is a skill
- **Projects:** a deck of project cards, held in painted hands
- **Writeups:** a bookshelf of CTF writeups
- **Work & Education:** an airship flying past each stop

Built with React, TypeScript, Vite and three.js (React Three Fiber), and
hosted on Cloudflare Pages.

## Running it

    npm install
    npm run dev       # http://localhost:5173
    npm test
    npm run build
